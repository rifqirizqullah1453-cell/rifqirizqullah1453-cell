### About

I'm **Rifqi Rizqullah** — Electrical & Electronics Engineering student at Bartın University, Türkiye, originally from Bandung, Indonesia.

I build **W.I.N.T.E.R.**, a local-first autonomous AI agent OS: a FastAPI core, Postgres + pgvector for long-term memory, Redis, n8n automations, and Ollama serving models on my own machine. Cloud is the fallback, never the default.

Ex robotics extracurricular teacher, so hardware still pulls at me. I ship first and understand deeper each pass — plus small web products on the side.

```text
focus     autonomous agents, local inference, memory
building  W.I.N.T.E.R. — 6 agent roles
studying  Electrical & Electronics Engineering
based in  Bartın, Türkiye
```
