## 🧠 About Me

**Rifqi, here** — an Electrical & Electronics Engineering student at Bartın University, Türkiye, originally from Bandung, Indonesia.

I'm building **W.I.N.T.E.R.**, a locally-run autonomous AI agentic OS: FastAPI core, Postgres + pgvector memory, Redis, n8n automations, and Ollama serving local models. Cloud fallback only when the local box can't take it.

Former robotics extracurricular teacher, so hardware still pulls at me. These days I code the "vibe" way — ship first, understand deeper each pass — while shipping small web products on the side (SANAMA Coffee, Kozi Coffee).

Goal: write systems that keep running when I close the laptop.
